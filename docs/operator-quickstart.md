# Operator Quickstart — Other Retail Sale in Non-Specialized Stores

Shortest path from clone to a verified local dry-run for **ISIC 4719** (`cloud-itonami-isic-4719`).

## Prerequisites

- Clojure 1.12+ (`clojure --version`)
- Java 17+
- Git

No invented metrics; this is a governed OSS blueprint, not a hosted SaaS demo.

## 1. Clone

```bash
git clone https://github.com/cloud-itonami/cloud-itonami-isic-4719.git
cd cloud-itonami-isic-4719
```

## 2. Run tests

```bash
kbb -M:test
```

Expect green if maturity is `implemented`. Fix failures before operating.

## 3. Run one store day

```bash
kbb -M:dev:run
```

`merchandiseops.sim` now walks a full Andon-shaped day on `store-1`
(roster, hire request, inbound, sales, restock, concern) and a HARD-held
day on unverified `store-3`. A till variance reuses the concern op — it
does not deposit cash. Hire, concern, and cash-up discrepancy always
wait for a human.

## 4. Open the product face

The live face is
https://cloud-itonami.github.io/cloud-itonami-isic-4719/

https://cloud-itonami.github.io/cloud-itonami-isic-4719/samples/operator-console.html
